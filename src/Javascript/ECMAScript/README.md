**(Portuguese)**

**O que é?**

O ECMAScript (ES) é uma especificação da linguagem de programação JavaScript. A especificação é mantida pela ECMA International. Nada mais é do que um padrão que define a linguagem de programação JavaScript, de forma que todos os navegadores possam implementar a mesma linguagem de forma consistente. Cada nova versão do ECMAScript traz novas funcionalidades, melhorias para a linguagem e correções de bugs. A partir da versão ES6, a ECMA International decidiu lançar uma nova versão a cada ano, com o objetivo de trazer novas funcionalidades e melhorias para a linguagem de forma mais rápida, por isso em muitos lugares você verá o ECMAScript ES6 como ECMAScript 2015 ou ES2015.

**(English)**

**What is it?**

ECMAScript (ES) is a specification of the JavaScript programming language. The specification is maintained by ECMA International. It is nothing more than a standard that defines the JavaScript programming language, so that all browsers can implement the same language consistently. Each new version of ECMAScript brings new features, language improvements, and bug fixes. From version ES6, ECMA International decided to release a new version every year, with the aim of bringing new features and improvements to the language faster, so in many places you will see ECMAScript ES6 as ECMAScript 2015 or ES2015.
